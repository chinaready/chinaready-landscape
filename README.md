# Chinaready China Tech Landscape

An open-source `landscape2` site that maps global developer services to China-ready alternatives, operating notes, and product profiles.

This repository intentionally keeps the standard CNCF `landscape2` workflow. Contributors familiar with CNCF Landscape should be able to recognize the data model, logo folder, settings file, guide file, and generated static preview.

## What This Is

- A Chinaready-maintained landscape data set.
- A local preview site generated by the official `landscape2` CLI.
- A source-backed map of China-market developer services for global software teams.

## What This Is Not

- It is not a fork of `landscape2`.
- It is not a custom frontend.
- It is not a definitive endorsement list.

## Local Preview

Build the branded preview:

```bash
npm run validate
npm run build
npm run verify
```

Serve the generated site:

```bash
node scripts/landscape2.mjs serve --landscape-dir build
```

Open:

```text
http://127.0.0.1:8000
```

Production target:

```text
https://landscape.chinaready.co
```

The GitHub Actions workflow deploys `main` to Cloudflare Pages with:

```bash
npx wrangler pages deploy build --project-name chinaready-landscape --branch main
```

Required repository secrets:

- `CLOUDFLARE_API_TOKEN`
- `CLOUDFLARE_ACCOUNT_ID`

See `docs/deployment.md` for the Cloudflare Pages project, custom domain, and CI model.

## Main Files

- `landscape.yml` - categories, subcategories, and product entries.
- `hosted_logos/` - SVG logos referenced by `landscape.yml`.
- `settings.yml` - `landscape2` site configuration and Chinaready brand settings.
- `guide.yml` - explanatory guide content.
- `vendor/chinaready-design-system/` - vendored Chinaready design system assets used by the local preview.
- `assets/chinaready-landscape.css` - small landscape-specific Chinaready CSS override.
- `scripts/landscape2.mjs` - cross-platform wrapper around the official `landscape2` release binary.
